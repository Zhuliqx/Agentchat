## 1. 查询改写实验（2026-08）

### 1.1 结论

- 两档改写（`rule` / `llm`）在书面集 40 条 / 口语集 8 条上，MRR 均与基线持平（**0.944 / 0.938**，零降损）；
- 端到端（口语集 8 条，LLM-judge）：faithfulness **0.975 → rule 0.863 / llm 0.853**——改写让生成侧变差；
- **决策：默认关闭**；若启用走「触发式」（仅低召回 query）。

### 1.2 三个工程发现

1. 对话式 prompt 被模型当聊天（输出"好的，请提供…"）→ `SystemMessage` + one-shot 示例 + 拒绝词回退（`_REFUSAL_MARKS`）；
2. 跨路 rerank 分数不可比（"双路各自精排再合并" MRR 0.938→0.917）→ 只合并召回、**统一精排一次**；
3. 短改写 query 精排不稳（rank1→rank2）→ **精排固定用原 query**，改写只扩召回。

### 1.3 当时系统基线（GT 40，rewrite off）

**CP 0.925 / CR 0.963 / faithfulness 0.923 / relevancy 1.0**。

### 4.5 生成策略迭代 v4→v6→v7（faithfulness）

| 版本 | 做法 | 全量 Faith | 结果 |
|------|------|-----------|------|
| v4 | 无推理引导 | 0.940 | q31/q37 保守回答 |
| v6 | 强鼓励推理 | **0.889 ↓** | q31/q37 提升，但否定型 q28 幻觉回归 |
